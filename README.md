# 漫画リーダー GUI

シンプルで安定した漫画リーダーアプリケーションです。

## 🌟 主な機能

- 📁 フォルダから自動的に章・話を検出
- 📖 PNG/JPEG画像の表示（自動リサイズ対応）
- ⬅️➡️ 前後のページナビゲーション
- 📚 最後のページから自動的に次の章へ移動
- 🔀 ドロップダウンから任意の章を選択可能
- 📊 プログレスバーでページ進捗を表示
- 🔢 ページ番号を入力して直接移動
- 💾 **最後に読んだ位置を自動保存**（ウィンドウサイズ・位置も記憶）
- ⌨️ **豊富なキーボードショートカット**
- 🖐 **タッチモード対応**（タッチスクリーンPC向けにUIを拡大）
- 🖱 **マウスホイール対応**
- 🎯 **フルスクリーン対応**（F11キー）
- 📝 **詳細なログ出力**
- ⚡ **画像キャッシング**（最大10個を メモリに保持で高速化）

## 📊 本格運用向け改善

### 🔧 エラーハンドリング
- 包括的な例外処理
- ファイルアクセス権限の確認
- 詳細なエラーメッセージ表示

### 📝 ロギング機能

- ログファイルは `~/.comic_reader_logs/` に保存
- 日付ごとのログファイル（`comic_reader_YYYYMMDD.log`）

### 💾 設定の永続化
- ウィンドウサイズと位置を保存
- ウィンドウ最大化状態を記憶
- 最後に読んだフォルダ・章・ページを復元
- 最終保存時刻も記録

### ⚡ メモリ管理
- 画像キャッシング（最大10個）
- 自動的に古い画像をメモリから削除
- アプリケーション終了時にリソース解放

### 🛡️ 安定性
- スレッドセーフな実装
- 再起動可能な設計
- 破損ファイルへの耐性

### 🎨 高品質画像表示
- **段階的リサイズ**: 大幅な縮小時に品質低下を防止
- **LANCZOSアルゴリズム**: シャープネスを保持した最高品質の画像処理
- **色空間最適化**: PNG/GIF/BMPを自動的にRGBに統一
- **アスペクト比保持**: 画像の歪みを完全に防止

## 📋 必要な環境

- Python 3.7+
- Pillow（画像処理ライブラリ）

## 🚀 インストール

1. Pythonをインストール（未インストールの場合）
2. 依存パッケージをインストール：
   ```bash
   pip install -r requirements.txt
   ```

## 🎨 画質最適化（高品質表示）

GUI で画像を表示すると画質が低下しやすいという問題に対応しています：

### ✨ 実装されている最適化手法

#### 1. 段階的リサイズ
- **大幅な縮小時（50%以下）**: 最初の段階で50%に縮小してから最終サイズへ
- **効果**: メモリの不要な情報が失われるのを防止
- **例**: 2000×3000px → 1000×1500px → 最終サイズ

#### 2. 高品質リサイズアルゴリズム
- **LANCZOS 法**: ボックスフィルタやバイリニア法より高品質
- **シャープネス保持**: エッジの鮮明さを維持
- **色の正確性**: RGB領域での正確な補間

#### 3. 色空間の最適化
- **RGB統一**: PNG（パレット）、GIF、BMPを自動的にRGBに変換
- **RGBA処理**: 透過PNG は白背景で合成（品質維持）
- **効果**: Tkinter の色深度制限に対応

#### 4. メモリキャッシング
- **LRU キャッシュ**: 最大10枚の高品質画像をメモリに保持
- **効果**: ページめくり時に即座に表示可能（リサイズ不要）

#### 5. Windows DPI 対応
- **高 DPI 表示を有効化**: Windows の DPI awareness を設定
- **効果**: 高解像度ディスプレイでGUIがよりシャープに表示される
- **特にタッチPCで有効**: UIの拡大とタッチ操作が鮮明になる
- **ディスク I/O削減**: 連続ページ閲覧が高速

#### 5. アスペクト比保持
- **歪み防止**: 画像の縦横比を完全に保持
- **余白対応**: 小さい画像の場合は等倍表示（ぼけ防止）

### 📊 画質比較

| 手法 | 品質 | 速度 | メモリ |
|------|------|------|--------|
| 標準(BILINEAR) | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ |
| LANCZOS | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ |
| **このアプリ（段階的+LANCZOS）** | **⭐⭐⭐⭐⭐** | **⭐⭐⭐** | **⭐⭐⭐** |

### ⚡ パフォーマンスチューニング

最初のページ読み込みで数秒かかる場合：
- **原因**: 大型画像の高品質リサイズ処理
- **解決法**: 通常は2ページ目以降キャッシュから即座に表示
- **回避法**: キャッシュサイズを増やす（ソースコード編集）

## 📁 フォルダ構成

```
M:\mangas\******\*********\
├─第1話/
│  ├─page_001.png
│  ├─page_002.png
│  └─...
├─第2話/
│  └─...
└─...
```

- **ルートフォルダ** ：複数の章フォルダを含む
- **章フォルダ** ：命名は任意（例：第1話、第2話、Chapter 1など）
- **ページ画像** ：PNG または JPEGファイル
  - ファイル名は昇順でソート（page_001.png, page_002.pngなど）

## 💾 保存される情報

### 設定ファイル
- **位置**: `~/.comic_reader/config.json`
- **内容**:
  - 最後に読んだフォルダパス
  - 最後に読んだ章・ページ
  - ウィンドウサイズと位置
  - ウィンドウ最大化状態

### ログファイル
- **位置**: `~/.comic_reader_logs/`
- **ファイル**: `comic_reader_YYYYMMDD.log`
- **内容**: 全操作のタイムスタンプ付きログ

## 🔧 トラブルシューティング

### 画像の画質が荒い・ぼやけている
- **デフォルト**: LANCZOS + 段階的リサイズで最適化済み
- **チェック**:
  - Pillow が最新版か確認: `pip install --upgrade Pillow`
  - 元画像の解像度を確認（解像度が低い場合は改善不可）
  - 画像形式がPNG/JPEGか確認（他の形式は自動変換される）
- **ソースコード調整** (main.py):
  - `MAX_CACHE_SIZE` を増やす（メモリに余裕があれば）
  - `_high_quality_resize()` メソッドの閾値を調整可能

### 画像が表示されない
- フォルダに PNG/JPEG ファイルがあるか確認
- ファイル拡張子が小文字（.png, .jpg）か確認
- ログファイルを確認: `~/.comic_reader_logs/`

### ページめくりが遅い
- **初回読み込み**: LANCZOS リサイズのため数秒かかる場合あり
- **その後**: キャッシュから即座に表示（通常0.1秒以内）
- **対応**:
  - `MAX_CACHE_SIZE` を増やす
  - 環境によって5-10秒は正常（ノートパソコン等）

### パフォーマンスが遅い
- ログレベルを確認（DEBUG時は遅くなる可能性がある）
- フォルダ内のファイル数が多すぎないか確認
- メモリ使用量が多すぎないか確認（キャッシュサイズ調整）

### Pillowのエラー
```bash
pip install --upgrade Pillow
```

### ファイルアクセス権限エラー
- ファイルの読み取り権限を確認
- Windowsのセキュリティソフトがブロックしていないか確認

## 🔍 ログの確認

```bash
# ログフォルダを開く
cd ~/.comic_reader_logs

# 最新ログを表示（Windows PowerShell）
Get-Content comic_reader_*.log -Tail 50
```

## 📊 動作確認

1. `python main.py` で起動
2. ログが出力されているか確認
3. フォルダ選択して画像が表示されるか確認
4. ページナビゲーションが動作するか確認
5. アプリケーション終了後、`config.json` が作成されているか確認

## 🎯 推奨設定

- フォルダ内のファイル数：1万個以下（パフォーマンス）
- ファイル名形式：`page_001.png`, `page_002.png`（自然順ソート対応）
- 画像解像度：1280x960以上推奨
